# 实验04 CSS布局实战——网站首页
> 课程：Web前端开发实验
> 实验名称：CSS布局实战——在线学习平台首页开发

## ✅ 实验简介
本实验使用 HTML + CSS 完成在线学习网站首页静态页面开发，主要利用 **Flex 弹性布局** 实现页面排版，不使用 JavaScript。页面包含网站头部、Banner横幅区、精品推荐、精品课程、学科分类、底部版权等模块，实现元素居中、横向排列、卡片悬浮动画等效果。

## 📁 项目目录结构


网站首页资料/
├── index.html          # 主页结构文件
├── css/
│   ├── base.css        # 基础重置样式（清除浏览器默认样式）

├── images/             # 小图标素材（logo、搜索图标等）

## 🛠️ 开发环境
- 代码编辑器：Visual Studio Code（VS Code）
- 插件：Live Server（用于本地实时预览页面）
- 浏览器：Chrome / Edge
- 技术栈：HTML5、CSS3、Flex弹性布局

## 🚀 运行方式
1. 使用 VS Code 打开【网站首页资料】整个文件夹
2. 找到 `index.html`，右键选择 `Open with Live Server`
3. 自动在浏览器打开预览，修改 HTML / CSS 文件保存后页面自动刷新

## 📌 页面模块说明
1. **header 头部区域**：Logo、主导航栏、搜索框、用户信息
2. **Banner 横幅区域**：左侧分类侧边栏、右侧课程预告卡片
3. **精品推荐区域**：热门技术标签横向展示
4. **精品课程区域**：课程卡片，2行5列排列，包含hover上浮阴影动画
5. **学科课程区域**：前端工程师课程分区，图文混排布局
6. **footer 底部版权区**：版权信息、APP下载、关于我们等链接

## 💡 核心知识点
1. CSS 样式重置，消除浏览器默认内外边距、默认字体等差异
2. 版心设置：固定宽度，margin: 0 auto 实现整体居中
3. Flex 弹性布局，实现水平排列、左右对齐、垂直居中
4. CSS 过渡 `transition` 和 `transform`，实现hover悬浮动画
5. 背景图、图片引入，相对路径使用
6. 类名规范，模块化书写，结构与样式分离
